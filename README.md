### 5. Sprint Planning (Sprint 1)
* **Sprint Goal:** Entregar un prototipo navegable en Angular que permita transicionar entre las pantallas de acceso y visualizar el layout base del Dashboard.
* **Definition of Done (DoD):**
    * El código compila sin errores en la terminal.
    * La navegación entre pantallas (RouterLink) funciona correctamente.
    * El diseño CSS respeta los estándares institucionales de la UNI.
    * El repositorio en GitHub está actualizado.

### 6. Sprint Execution
El equipo realizó Dailies para sincronizar la maquetación. Se incluyó una fase de investigación previa liderada por Peter sobre el flujo de trabajo en Git y los lineamientos gráficos de la UNI para asegurar la consistencia del prototipo.

### 7. Sprint Review (Revisión)
* **Demostración:** Exhibición de la navegación fluida entre Login, Registro y el Dashboard.

### 8. Sprint Retrospective (Retrospectiva)
* **Aciertos:** La investigación sobre Git ayudó a evitar conflictos en el repositorio. La distribución de tareas permitió que los miembros con menos carga apoyaran en el diseño de pantallas críticas.
* **Oportunidades:** Se requiere estandarizar las librerías de estilos desde el inicio del próximo Sprint.

### 9. Cierre del Sprint
**Incremento Entregado:** Conjunto de vistas estáticas y navegables (Frontend) con base documental en investigación técnica y diseño institucional.
